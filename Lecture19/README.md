# Method of Separation of Variables

Lecture 19 in the course task list: fixed, free, and mixed endpoint conditions; orthogonality and modal coefficients; finite-interval heat conduction; and Laplace's equation in a rectangle.

- [Read online](lec19.md)
- [LaTeX source](lec19.tex)
- [Compiled PDF](lec19.pdf)

Sources: `12.20.pdf`, PDF pages 2-11; `12.27.pdf`, PDF pages 1-6. The second file continues the separation-of-variables material before introducing nonhomogeneous problems.

Compile with `latexmk -pdf lec19.tex` from this directory, or run `pdflatex lec19.tex` twice. The layout follows `Templates/template.tex`; only standard LaTeX packages are needed.
