# Lecture11

English notes based on 11.8.pdf. Uses Templates/template.tex, with mathtools for definition symbols and url for source references.

- Main lecture: [Lecture11.md](Lecture11.md), [Lecture11.tex](Lecture11.tex), [Lecture11.pdf](Lecture11.pdf).
- Exercises and worked practice: [Lecture11_exercises.md](Lecture11_exercises.md), [Lecture11_exercises.tex](Lecture11_exercises.tex), [Lecture11_exercises.pdf](Lecture11_exercises.pdf).

The main lecture expands definitions, hypotheses, and derivations. The supplement preserves original calculation lines and adds verification notes for errors and missing conditions.

Compile each .tex file twice with pdflatex -interaction=nonstopmode -halt-on-error followed by the filename. Both sources are standalone and require no local images or custom classes.
