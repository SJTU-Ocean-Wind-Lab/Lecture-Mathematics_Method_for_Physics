# Lecture10

English notes based on 11.3.pdf. Uses Templates/template.tex, with mathtools for definition symbols and url for source references.

- Main lecture: [Lecture10.md](Lecture10.md), [Lecture10.tex](Lecture10.tex), [Lecture10.pdf](Lecture10.pdf).
- Exercises and worked practice: [Lecture10_exercises.md](Lecture10_exercises.md), [Lecture10_exercises.tex](Lecture10_exercises.tex), [Lecture10_exercises.pdf](Lecture10_exercises.pdf).

The main lecture expands definitions, hypotheses, and derivations. The supplement preserves original calculation lines and adds verification notes for errors and missing conditions.

Compile each .tex file twice with pdflatex -interaction=nonstopmode -halt-on-error followed by the filename. Both sources are standalone and require no local images or custom classes.
