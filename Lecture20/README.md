# Integral Transforms and Nonhomogeneous Problems

Lecture 20 in the course task list: Fourier solution of the whole-line heat equation, the heat kernel, boundary homogenization, and eigenfunction expansion with a time Laplace transform for forced strings.

- [Read online](lec20.md)
- [LaTeX source](lec20.tex)
- [Compiled PDF](lec20.pdf)

Sources: `12.15.pdf`, PDF pages 13-17; `12.27.pdf`, PDF pages 7-12. The final example is completed through an explicit solution, using both modal convolution and a stationary particular solution.

Compile with `latexmk -pdf lec20.tex` from this directory, or run `pdflatex lec20.tex` twice. The layout follows `Templates/template.tex`; only standard LaTeX packages are needed.

See [PDE source and validation notes](../PDE_SOURCES.md) for the source mapping and mathematical corrections.
